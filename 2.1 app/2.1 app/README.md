# DeepScan

DeepScan is a deepfake detection web application that allows users to upload and analyze media files for potential manipulation.

## Features

- Upload images, videos, and audio files
- Multiple detection types:
  - Image Deepfake Detection
  - Video Manipulation Check
  - Audio Synthesis Detection
- Detailed analysis results with authenticity scores
- AI detection reports and tampering indicators

## Files

- `index.html` - Upload page for media analysis
- `results.html` - Verification results page

## Usage

1. Open `index.html` in a web browser
2. Upload your media file (jpg, png, mp4, wav)
3. Select detection type
4. Click "Analyze File" to view results
